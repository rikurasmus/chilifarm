# chilifarm

* User can create an account and use it to log in
* User can create new chili growing projects and modify or delete existing ones
* User can add pictures of their plant
* User can view other users plant files / projects
* User can search different projects with searchwords related to the project or the plant
* User has access to their profile information such as all of their own projects and stats
* User can define information related to their project upon creating a new chili plant growing project such as species, their level of experience, desired outcome for the project, chili hotness level, etc.
* User can add updates to their project and leave feedback on other users' projects
